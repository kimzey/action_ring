Installing ActionRing

A 2‑minute guide to getting the ring running on your Mac.

Requires · macOS 14 (Sonoma)+ Best with · a mouse that has a side button You need · the ActionRing‑<version>.dmg file
Why the extra clicks? ActionRing isn't notarized by Apple yet, so macOS shows an "unidentified developer" warning the first time you open it. The steps below are the normal, Apple‑supported way to open such an app — you only do them once.

1Open the disk image

Double‑click ActionRing‑<version>.dmg. A window opens showing ActionRing and an Applications shortcut.

2Drag it into Applications

Drag the ActionRing icon onto the Applications folder in the same window.

┌─────────────────────────────────────┐ │ [ ActionRing ] ───▶ [ Applications ] └─────────────────────────────────────┘ drag this onto this

You can then eject the disk image (drag it to the Trash, or click ⏏ in Finder).

3Open it the first time

Don't double‑click yet — macOS will block it. Instead:

  1. Open your Applications folder.
  2. Right‑click (or hold Control and click) ActionRing.
  3. Choose Open.
  4. In the dialog, click Open again.

That's the one‑time unlock. After this it opens normally — double‑click, Spotlight, anything.

No "Open" button? On newer macOS the dialog may only show "Done". Go to System Settings → Privacy & Security, scroll down, and click "Open Anyway" next to the ActionRing message.
Or unlock it instantly in Terminal:
xattr -dr com.apple.quarantine /Applications/ActionRing.app

4Grant Accessibility (required)

ActionRing detects your trigger button with a system event tap, which macOS gates behind Accessibility. Without this, the ring won't appear when you press the button.

  1. System Settings → Privacy & Security → Accessibility
  2. Find ActionRing and turn its switch on.
    Not listed? Click +, pick ActionRing from Applications, then enable it.
  3. If the trigger still doesn't respond, quit and reopen ActionRing.
Privacy This is the only permission ActionRing asks for. It makes no network calls and never reads your typed text, window titles, or file contents.

5Find it and try it

ActionRing has no Dock icon — it lives in the menu bar (top‑right, look for the ⊕ ring icon).

  • Click the menu‑bar icon → Preview Ring to watch it appear and follow your cursor (no permission needed for the preview).
  • Then hold the trigger button — by default the side/thumb button (Button 4). The ring appears at your cursor; drag toward a slice and release to fire it, or release in the center to cancel.
  • Open the menu‑bar icon → Settings… to change the trigger (there's a Record from mouse button), ring size, and slot count.
🎉 You're done. Hold your side button anywhere and the ring is there.

Troubleshooting

"ActionRing is damaged and can't be opened."

Gatekeeper on a quarantined, non‑notarized app — it isn't actually damaged. Run:

xattr -dr com.apple.quarantine /Applications/ActionRing.app

then open it again (or re‑do step 3's right‑click → Open).

Menu‑bar icon is there, but pressing the button does nothing.

Accessibility isn't active. Re‑check step 4. A reliable reset:

  1. Privacy & Security → Accessibility → toggle ActionRing off, then on.
  2. Quit ActionRing (menu‑bar icon → Quit) and reopen it.

The ring flashes and disappears instantly / looks faint.

Make sure you're running the copy in /Applications (step 2), not an older one. Quit any duplicate instances and reopen the installed one.

My mouse button isn't detected.

Open Settings → Record from mouse, then press the button you want. Avoid binding left/right click (Button 1/2) — use a side button so normal clicking still works.

How do I uninstall?

Quit ActionRing, then drag /Applications/ActionRing.app to the Trash. To also remove settings:

rm -rf ~/Library/Application\ Support/ActionRing

Building from source (developers)

If you have the repo and a Swift 6 toolchain instead of a .dmg:

make install     # build a release .app and copy it to /Applications
make bundle      # just build ./ActionRing.app
make dmg         # build a shareable ./dist/ActionRing-<version>.dmg

Then grant Accessibility as in step 4. See ActionRing.md for the full reference.

For whoever shipped this The "unidentified developer" prompt disappears entirely if the build is signed with a Developer ID and notarized by Apple (requires a paid Apple Developer account). Until then, the right‑click → Open / "Open Anyway" flow above is expected and safe for a build you trust.
